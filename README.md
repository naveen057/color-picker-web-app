# 🎨 Color Picker Web App

An interactive web application that allows users to select and work with colors through a simple and user-friendly interface.

## ✨ Features

* Interactive color selection
* Displays the selected color
* Real-time color updates
* Simple and responsive user interface
* Built using vanilla JavaScript

## 🛠️ Technologies

* **HTML5**
* **CSS3**
* **JavaScript**

## 📂 Project Structure

```text
color-picker-web-app/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/naveen057/color-picker-web-app.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

No additional installation is required.
